AgentRoute

System architecture

A request moves down this path once. Laya chooses the agent. The model selector chooses the model. A tool runs only when that agent needs it.

Watching the request.

  1. 01

    User request

    Natural-language text enters the API or the CLI.

  2. 02

    Classifier

    A baseline reading of intent, complexity, and confidence. Laya may replace it.

  3. 03

    Laya

    The decision layer. It is not a model, an agent, a provider, or a tool.

  4. 04

    Agent selection

    One of six agents: general, coding, reasoning, research, 3D, or web.

  5. 05

    Task profile

    Capability, complexity, context, output, and whether a tool is required.

  6. 06

    Model selection

    The best-fit model for that profile. The provider follows the model.

  7. 07

    Execution

    The selected agent calls the model. The router does not call a provider itself.

  8. 08

    Tools

    Blender, Playwright, or web search, only when that agent owns the tool.

  9. 09

    Evaluation and fallback

    The outcome is scored. A failed model stays inside the same agent and tries its fallback.

  10. 10

    Result

    The answer, the routing record, and any scene or page result return to the user.
